# FlyWireLLM v0.2.0 — Research Pretraining Readiness

## Release purpose

v0.2.0 marks the point where FlyWireLLM moves from the v0.1.0 blank-model
engineering baseline to a qualified research pretraining-ready Base-50M
foundation.

The release freezes the engineering contracts required to start the first
Base-50M research-only pretraining run:

- Base-50M-v1 architecture contract;
- 32K SentencePiece Unigram tokenizer identity and hash;
- source-rights and provenance lanes;
- privacy/quality screening;
- deterministic train/validation/holdout boundaries;
- global exact and near-duplicate handling;
- a qualified 500M Thai/English/technical research-only mixture;
- a checkpoint lineage frozen before optimizer step 1.

Base-50M itself has not been pretrained in this release.

## Base-50M-v1 contract

The L002 architecture remains frozen at:

- parameters: 50,213,376;
- vocabulary: 32,000;
- d_model: 512;
- layers: 12;
- query/KV heads: 8/2;
- d_ff: 1,408;
- initial context: 1,024;
- RMSNorm + RoPE + GQA + SwiGLU + tied embeddings.

The model remains random-initialized until a later pretraining stage executes
optimizer updates.

## Release assets

The intended v0.2.0 GitHub assets are:

- FlyWireLLM-v0.2.0-release.zip;
- FlyWireLLM-v0.2.0-document.zip;
- SHA256SUMS.txt.

The release ZIP contains source, configuration, scripts, tests and small
qualification metadata needed to reproduce the engineering state. It does not
contain the external raw corpora, the 1.68 GB global decision file, the
tokenizer binary, or a new model checkpoint.

The documentation ZIP contains the core project/release/result documents and a
release manifest.

GitHub additionally provides its normal source archives for the tag.

## Qualification

Before publication, the exact release commit must pass:

- full repository pytest;
- canonical L003 audit;
- final L003 freeze audit;
- external tokenizer/corpus/decision/summary re-hash;
- wheel build and package-version verification;
- MIT License inclusion in the wheel;
- release ZIP extraction/import smoke;
- documentation ZIP content verification;
- SHA-256 verification of all uploaded assets;
- exact main/origin-main synchronization;
- exact release tag target verification.

GitHub Actions are not claimed unless a workflow actually exists and runs.

## Claims boundary

v0.2.0 does not claim:

- Base-50M pretraining has started or completed;
- Thai or English understanding;
- conversational capability;
- benchmarked language quality;
- trained FlyWire knowledge in model weights;
- release-safe/public redistribution qualification for a future
  research-only-trained checkpoint.

The next model-development stage may start Base-50M research-only pretraining
only from the frozen L003 lineage and hashes.
