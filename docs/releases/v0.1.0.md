# FlyWireLLM v0.1.0 — Blank LLM Baseline

## Release purpose

v0.1.0 is the first FlyWireLLM release.

It publishes a **blank, random-initialized, training-ready causal language-model
baseline** together with the source code and engineering checks required to
continue development safely.

This is intentionally not the planned ~50M language model. It is a tiny smoke
baseline used to prove the architecture, tokenizer, training objective,
checkpoint provenance and packaging path before scaling.

## Baseline architecture

- decoder-only causal Transformer;
- RMSNorm;
- RoPE;
- grouped-query attention;
- SwiGLU feed-forward network;
- tied token embeddings / LM head;
- random initialization only;
- no imported pretrained weights.

Smoke profile:

- vocabulary: 260 tokens;
- hidden size: 64;
- layers: 2;
- query heads: 4;
- KV heads: 2;
- FFN size: 176;
- context: 128;
- parameters: 109,120.

## Tokenizer

v0.1.0 uses the training-free UTF-8 byte tokenizer baseline.

It losslessly round-trips:

- Thai;
- English;
- mixed Thai/English;
- technical identifiers;
- arbitrary UTF-8 Unicode.

This proves encoding compatibility only. It does not imply language
understanding.

## Blank checkpoint

The release contains a deterministic-seed step-0 checkpoint generated with the
tracked smoke configuration.

Checkpoint metadata records:

- pretrained = false;
- external_pretrained_weights = false;
- initialization_origin = random;
- random_initialization_origin = true;
- knowledge_in_weights_claimed = false;
- untrained = true;
- training_step = 0;
- initialization seed.

The blank checkpoint is suitable for engineering continuation and pretraining
pipeline tests. It is not a useful conversational model before training.

## Qualification

The release must pass all of the following before publication:

- full pytest suite;
- Thai and English tokenizer round-trip;
- causal future-token leakage regression;
- forward/loss/backward;
- optimizer smoke update;
- step-0 checkpoint safe reload with weights_only=True;
- one-step smoke checkpoint safe reload;
- wheel build;
- MIT License inclusion in wheel;
- release ZIP extraction and import test;
- asset SHA-256 verification;
- exact main/origin-main synchronization.

## Claims boundary

v0.1.0:

- is training-ready;
- is random-initialized;
- contains no pretrained language knowledge;
- contains no trained FlyWire knowledge;
- cannot yet converse;
- has no Thai/English language-quality qualification.

The planned second stage defines the larger Base-50M direction, learned
Thai/English tokenizer benchmark and real pretraining-data/token budget.
